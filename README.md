# Road Condition Mapping

Road Condition Mapping plans a local maintenance-triage tool that turns licensed images into damage candidates and evidence reports. Observations with trustworthy coordinates can become a mapped inventory; unlocated images remain an image-review queue. The tool never invents geographic positions or presents review priorities as engineering measurements.

The first functional public release, in month 7 after activation, includes detection, evidence review, CSV export and a map demonstrated with explicitly synthetic georeferenced scenes. Public real-image evaluation is conditional on resolving dataset rights and obtaining adequate existing annotations. RDD2022 license discrepancies remain a blocking data gate, not an assumed permission.

The portfolio runs one active project at 16 hours weekly. This plan allocates 640 work hours plus 160 reserve hours, completing within 50 active weeks. Technical completion requires no fleet, field collection, paid labeling, customer data or commercial mapping account.

See [the execution plan](docs/EXECUTION_PLAN.md) and [the backlog](planning/backlog.json). The existing `cv-road-condition-mapping` repository receives planning artifacts only.
